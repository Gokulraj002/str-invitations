# STR Invitations — strinvitations.in

Website for STR Invitations: wedding invitation videos, 3D short videos, invitation websites and RIP tribute videos.

**To edit prices, videos, text or images, see [EDITING_GUIDE.md](EDITING_GUIDE.md).**

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run sync:yt    # fetch new videos from the YouTube channel
```

Built with Next.js, React and Tailwind CSS.
